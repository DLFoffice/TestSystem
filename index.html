# ชื่อโครงการ (คลิกบรรทัดเพื่อดูรายละเอียด) ยุทธศาสตร์ งบอนุมัติ (บาท) ใช้ไป (บาท) PO (บาท) ใช้+PO (บาท) คงเหลือสุทธิ สถานะ ตัวชี้วัด จัดการ
📊 เลือกโครงการเพื่อรายงานผลการดำเนินงาน
เลือกโครงการที่กรอกเข้าระบบไว้แล้วจากรายการด้านล่าง (จัดกลุ่มตามยุทธศาสตร์) เพื่อให้ข้อมูลที่รายงานถูกผูกกับโครงการและหมวดหมู่ยุทธศาสตร์ที่ถูกต้องเสมอ หรือคลิกเลือกโครงการจากตารางด้านล่างได้โดยตรง
📋 ข้อมูลจากแผนโครงการ (อ้างอิง — ดึงจากระบบโครงการอัตโนมัติ)
1. วัตถุประสงค์
2. เป้าหมาย
2.1 เป้าหมายเชิงปริมาณ
2.2 เป้าหมายเชิงคุณภาพ
3.2 การวัดและประเมินผล (ตัวชี้วัดโครงการ)
ระบบดึงรายชื่อตัวชี้วัดจากแผนโครงการ (ข้อการวัดและประเมินผล) มาให้อัตโนมัติ — กรอกแค่ "ค่าเป้าหมายที่ทำได้" และผลบรรลุ/ไม่บรรลุของไตรมาสนี้ หรือแก้ไข/เพิ่ม/ลบรายการได้ตามต้องการ
ที่ตัวชี้วัดโครงการค่าเป้าหมายที่ทำได้ผลการดำเนินงาน
3. ผลการดำเนินงานโครงการ
แต่ละไตรมาสบันทึกแยกจากกัน — สลับไตรมาสเพื่อกรอก/แก้ไขผลของไตรมาสนั้นได้โดยตรง
ระบบดึงรายชื่อกิจกรรมและ "งบประมาณอนุมัติ" จากแผนโครงการ (ข้อรายละเอียดงบประมาณ) มาให้อัตโนมัติ — กรอกแค่ "ใช้ไป" ของไตรมาสนี้ หรือแก้ไข/เพิ่ม/ลบรายการได้ตามต้องการ

Sync ข้อมูลกับ Google Sheet
ส่งข้อมูลโครงการทั้งหมดที่มีอยู่ขึ้น Google Sheet ทันที (เขียนทับข้อมูลเดิม)
ส่งออกข้อมูล (CSV)
ดาวน์โหลดข้อมูลโครงการทั้งหมดเป็น CSV แล้วนำเข้า Google Sheets ได้เลย
รูปแบบข้อมูลที่รองรับ
Sheet ควรมีหัวคอลัมน์แถวแรกดังนี้:

id | name | strategy | budget | spent | po | status | result | kpi | problems | solutions | quarter | owner | committees | image_count | images_json | lastEditedBy | lastEditedByPosition | lastEditedAt

• strategy = 1, 2, 3, 4 หรือ 5 (งบบริหารสำนักงาน)
• budget, spent, po = จำนวนเงิน (ตัวเลข ไม่ใส่ comma)
• status = done / progress / pending
• kpi = ตัวชี้วัด คั่นด้วย | (pipe)
• quarter = 1, 2, 3, 4 หรือ all
• owner = ผู้รับผิดชอบ / หน่วยงาน
• committees = JSON array เช่น ["นโยบายและแผนงาน","วิชาการ"]
• images_json = JSON array ของรูปภาพ [{"name":"...","url":"...","publicId":"..."}] (Cloudinary URL ไม่ใช่ base64)
• lastEditedBy = ชื่อผู้แก้ไขล่าสุด (ดึงจากบัญชีที่ login อัตโนมัติ) — คอลัมน์ใหม่
• lastEditedByPosition = ตำแหน่งของผู้แก้ไขล่าสุด — คอลัมน์ใหม่
• lastEditedAt = วันเวลาที่แก้ไขล่าสุด (ข้อความ) — คอลัมน์ใหม่

# กิจกรรมโครงการ ประเภท และปัจจัยความเสี่ยง ระดับความเสี่ยง การจัดการความเสี่ยง ระยะเวลา งบประมาณ ผู้รับผิดชอบ
* แถวจะปรากฏโดยอัตโนมัติจากข้อมูล PRM 01-03 — กรอกแผนการจัดการในแต่ละแถว

ระดับความเสี่ยงคะแนนคำอธิบาย
สูงมาก16 – 25ระดับที่ไม่สามารถยอมรับได้ จำเป็นต้องเร่งจัดการความเสี่ยงให้อยู่ในระดับที่ยอมรับได้ทันที
สูง10 – 15ระดับที่ไม่สามารถยอมรับได้ โดยต้องจัดการความเสี่ยงเพื่อให้อยู่ในระดับยอมรับได้
ปานกลาง5 – 9ระดับที่ยอมรับได้ แต่ต้องมีการควบคุมเพื่อป้องกันไม่ให้ความเสี่ยงไปยังระดับที่ยอมรับไม่ได้
ต่ำ1 – 4ระดับที่ยอมรับได้ โดยใช้วิธีควบคุมปกติตามขั้นตอนการปฏิบัติงานที่กำหนด
